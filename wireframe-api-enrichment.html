POST /v1/lists/{list_id}/enrich Batch enrich all accounts in a list (new)

Request

{ "account_ids": [1, 2, 3], // optional — omit for all "providers": ["apollo"], // optional — defaults to waterfall "target_titles": [ "VP Engineering", "CTO" ] // optional — defaults to ICP }

Response

{ "queued": 5, "skipped": 0, "already_enriched": 0, "providers_available": [ "apollo" ] } // Poll GET /v1/lists/{id} for progress

Waterfall internals

What happens inside a single enrichment call for one company.

Orchestrator logic

for each company: contacts = [] # 1. Try Apollo (free) if apollo_connected: contacts = apollo.search(domain) # 2. Need more? Try PDL if len(contacts) < target and pdl_connected: more = pdl.search(domain, titles) contacts += dedupe(more) # 3. Still need more? Try LeadMagic if len(contacts) < target and leadmagic_connected: more = leadmagic.enrich(domain, titles) contacts += dedupe(more) # 4. Save whatever we found save_enriched_contacts(contacts) update_enrichment_status("completed")

Deduplication

# Contacts from multiple providers # may overlap — same person found # by Apollo AND PDL # Dedupe strategy: # 1. Match on email (exact) # 2. Match on linkedin_url # 3. Match on name + company # When merging duplicates: # - Keep most complete record # - Prefer verified email # - Track which provider found it
source tracking: Each contact stores which provider found them. This helps users understand data quality and helps Auggie optimize the waterfall order over time.

Revenue model options

A) Free orchestration

BYOK only — $0 to Auggie
User pays their providers
Auggie charges for scoring + writing
Enrichment is a free value-add

Pro: No COGS, great retention
Con: No enrichment revenue

B) Credit per enrichment

Charge 0.5 credits/company
User BYOK = pure margin
No key? Auggie pays provider
Credit covers Auggie's cost

Pro: Revenue + fallback
Con: Friction for BYOK users

C) Tiered (recommended)

BYOK = free enrichment
No key = Auggie-managed
Auggie-managed costs credits
Premium providers cost more

Pro: Best of both worlds
Pro: Incentivizes key connection
