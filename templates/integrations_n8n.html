Auggie + n8n

Add deep account research to any n8n workflow.

Research companies, score by pain, and generate messaging — triggered by any event in your stack.

What you can build

📥

New lead enrichment

When a lead enters your CRM, auto-research their company and score by pain before your team follows up.

💬

Messaging generation

Pull talking points from Auggie and feed them into your email drafts — outreach that references real pain.

🚦

Lead routing

Route high pain-score accounts to your best reps, and deprioritize low-fit companies automatically.

📋

List processing

Feed a Google Sheet of target accounts into Auggie and get scores + research back in bulk.

How to set it up

  1. 1

    Create an Auggie API key

    Go to /api-keys and create a new key. Copy it — you'll need it in the next step.

  2. 2

    Add an HTTP Request node

    In your n8n workflow, add an HTTP Request node. Set the method to POST and the URL to:

    https://auggie.app/v1/research
  3. 3

    Configure authentication

    Under Authentication, select Generic Credential Type > Header Auth. Set the name to Authorization and value to Bearer aug_your_key. In the body, send:

    {"company_url": "https://example.com"}
  4. 4

    Poll for results

    Add a Wait node (30 seconds) followed by another HTTP Request to GET https://auggie.app/v1/research/{job_id}. Use an IF node to check if status is completed — if not, loop back to the Wait node. Or, use an Auggie webhook to trigger a separate workflow on completion.

  5. 5

    Use the results

    Map scores.pain, scores.composite, and sections.talking_points to downstream nodes — CRM updates, email drafts, Slack alerts, etc.
