Sequences

Generate personalized outreach email sequences from completed research documents.

POST /v1/research/{doc_id}/sequence

Generate a 3-email outreach sequence from a completed research document. Requires a completed document ID.

sequence = client.create_sequence(doc_id=15)
for email in sequence["emails"]:
    print(f"Email {email['email_number']}: {email['subject']}")
curl -X POST https://auggie.tools/v1/research/15/sequence \
  -H "Authorization: Bearer aug_your_key"
const resp = await fetch("https://auggie.tools/v1/research/15/sequence", {
  method: "POST",
  headers: { "Authorization": "Bearer aug_your_key" }
});
const sequence = await resp.json();
