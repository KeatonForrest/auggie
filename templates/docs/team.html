Team

Manage organization members and roles via the API.

GET /v1/team

List all team members in your organization.

Response

{
  "object": "team",
  "members": [
    {"user_id": 1, "email": "admin@acme.com", "role": "admin"},
    {"user_id": 2, "email": "rep@acme.com", "role": "member"}
  ]
}
POST /v1/team/invite

Invite a new team member. Admin only.

Request body

{
  "email": "newrep@acme.com",
  "role": "member"
}

Response

{
  "object": "invite",
  "email": "newrep@acme.com",
  "role": "member"
}
PATCH /v1/team/members/{user_id}

Change a team member's role. Admin only.

Response

{
  "object": "team_member",
  "user_id": 2,
  "role": "admin"
}
DELETE /v1/team/members/{user_id}

Remove a team member. Admin only. Returns 204 on success.
