Export for Apollo

Why a CSV?

Apollo's API does not support creating email steps in sequences programmatically. Despite Auggie generating fully personalized, ready-to-send emails, Apollo provides no way to deliver them directly into sequences via their API. This CSV workaround uses Apollo's custom contact fields as the bridge.

One-time setup in Apollo (takes ~2 minutes):

  1. Go to Settings → Custom Fields → Contact
  2. Create these 10 text fields:
    auggie_composite_score auggie_pain_score auggie_fit_score auggie_timing_score auggie_email_1_subject auggie_email_1_body auggie_email_2_subject auggie_email_2_body auggie_email_3_subject auggie_email_3_body
  3. Create a 3-step sequence template where each email uses:
    Subject: {{auggie_email_1_subject}}
    Body: {{auggie_email_1_body}}
    (repeat for email 2 and 3)

Each time you export:

  1. Download the CSV below
  2. In Apollo: People → Import → upload the CSV
  3. Map the columns (Apollo remembers your mapping after the first time)
  4. Add the imported contacts to your sequence — hit activate

Apollo's column mapping is remembered per-workspace, so this gets faster after the first import.
