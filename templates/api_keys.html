Zapier / Make Webhooks

Register a Zapier or Make (Integromat) webhook URL to receive events when research completes. Use the webhook above — it works with any HTTP endpoint including Zapier Catch Hook and Make Custom Webhook triggers.

Payload format:

{
  "job_id": 123,
  "status": "completed",
  "document_id": 456,
  "error": null
}

The payload is signed with your webhook secret using HMAC-SHA256, sent in the X-Webhook-Signature header.

Quick Start

curl -X POST https://auggie.tools/v1/research \
  -H "Authorization: Bearer sk_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"company_url": "acme.com"}'
