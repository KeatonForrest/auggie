Auggie → Apollo Workflow

How personalized sequences get from Auggie into Apollo

Apollo's API does not expose an endpoint for creating email steps in sequences. Sequences can be created, contacts can be added — but the actual email content (subject lines, bodies) cannot be programmatically inserted. This is the sole reason a CSV workaround is required.

Apollo API Limitations

No sequence step creation POST /emailer_steps — undocumented, silently fails
No email template creation No API endpoint exists at all
Email accounts endpoint requires master key GET /email_accounts — 403 with standard keys
Contact custom fields underdocumented typed_custom_fields format not specified in API docs
Sequence creation works POST /emailer_campaigns — creates empty shell
Contact search works POST /mixed_people/api_search — by org or domain
Add contacts to sequence works POST /emailer_campaigns/{id}/add_contact_ids (needs email_account_id)
CSV import handles custom fields The only way to set custom field values on contacts at scale
